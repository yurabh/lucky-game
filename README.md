                                           Тестове завдання: Lucky Game

Додаток реалізовано суто як серверний вебдодаток на чистому PHP 8.2 із повною строгою типізацією відповідно до
архітектури MVC та принципу YAGNI.

Покрокова інструкція для запуску:

1. Переконайтеся, що на вашому ПК запущено Docker Desktop.
2. Скопіюйте файл конфігурації оточення:
   cp .env.example .env

3. Відкрийте термінал у кореневій папці проєкту та виконайте:
   docker-compose up -d

Доступні шляхи та маршрутизація (Routing):
Після успішного запуску контейнерів додаток буде доступний за такими адресами:

http://localhost:8080/ (або `/index.php`) - Головна сторінка. Тут відображається форма реєстрації з полями Username та
Phonenumber.

http://localhost:8080/register - Внутрішній маршрут обробки форми (POST-запит).
Після успішного заповнення форми додаток автоматично згенерує унікальний ключ посилання і перенаправить (REDIRECT) вас
на Сторінку А.

http://localhost:8080/page-a?token={унікальний_ключ} Сторінка А. Доступна лише за діючим унікальним посиланням (термін
дії - 7 днів).
Якщо посилання застаріло, було деактивовано або введено неправильно, додаток автоматично поверне вас на головну сторінку
з повідомленням про помилку.

Функціонал сторінки А:

Imfeelinglucky - Генерує випадкове число від 1 до 1000 та розраховує виграш.

History - Показує результати 3 останніх спроб гри.

Regenerate Link - Створює новий унікальний ключ для посилання та оновлює адресу в браузері.

Deactivate Link - Миттєво видаляє доступ за поточним посиланням та повертає на форму реєстрації.
